# Novelty assessment

Exact claim: For every nondecreasing locally finite infinite sequence (a_i) of positive integers with bounded numerical multiplicity, if every tail has gcd one and its finite subset sums meet every residue class modulo every positive integer, liminf_{X->infinity} (log 2)#{i:a_i<=X}/log X>1, sum_i ||alpha a_i||^2=infinity for every irrational real alpha (where ||x|| is distance to the nearest integer), and (S_m-a_{m+1})/a_{m+1}^beta tends to positive infinity for every real beta with 0<beta<1, where S_m=sum_{i=1}^m a_i, then there exist integers L>=0 and m_0>=1 such that for every m>=m_0, S_m>=2L and every integer in [L,S_m-L] is a subset sum of a_1,...,a_m using each labelled index at most once.
