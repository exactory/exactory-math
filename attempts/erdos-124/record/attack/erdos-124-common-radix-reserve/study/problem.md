# Problem study: common-radix seeds with a disjoint positive reserve

Date: September 8, 2026.

## Exact proposed claim

For every nonempty finite set D of distinct integers at least 3 with gcd(D)=1 for which there exist an integer B>=2, a nonempty finite set A of positive integers and a nonempty set C contained in D minus R, where R={B^a:a in A} is contained in D, such that sigma(R)=sum_{d in R}1/(d-1)>=1/2, gcd({B} union C)=1 and sigma(D minus (R union C))>=1, every integer k>=1 and every finite set F of labelled occurrences (d,j) with d in D and j>=k admit N(D,k,F) such that every integer n>=N is a sum of finitely many remaining occurrences d^j, each pair (d,j) used at most once; coincident numerical values from different pairs remain separately available.

This is a separate structural theorem, not the original all-base threshold-one
claim and not the arbitrary-base half-mass signed-unit assertion.
