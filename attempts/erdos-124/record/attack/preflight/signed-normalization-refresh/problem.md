## 3. Constraints on the next plan

No applicable all-input normalizer was found. Product-base digits, real bases, bounded numbers of summands and full modular coverage cannot be substituted for the actual labels. Node15's restricted scalar obstruction remains intact. This does not prove a barrier to every nonlinear method.

A distinct conditional construction is worth an exact separate study: use an accepted common-radix signed lattice for the large signed correction, and select only finitely many phase-aligned positive correction labels from a strict-mass complement. Each correction label must individually satisfy CP26's all-scale deletion invariant. Unlike the old node16 construction this would not dedicate entire correcting base streams. Unlike node8 it would not assume an uncontrolled support-cost bound for a finished gadget. Simultaneous congruence restrictions and logarithmic returns still require proof. This is a proposed hypothesis, not a theorem or an executed move.
