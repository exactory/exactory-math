## 1. The problem

Dittert's conjecture (Minc 1983, Conjecture 28). For `A` in `K_n`, the non-negative `n x n`
matrices with entry sum `n`, with row sums `r_i` and column sums `c_j`,

    phi(A) = prod_i r_i + prod_j c_j - per(A)  <=  2 - n!/n^n,

with equality only at `J_n/n`. Frontier as of 2026-09-02: `n = 2` (Sinkhorn 1984), `n = 3` (Hwang
1986/87), `n = 4` (arXiv:2607.29191), `n = 16` (arXiv:2607.19439), `n >= 17` (arXiv:2606.01531).
Open: `5 <= n <= 15`.

Notation used throughout: `gamma_n = n!/n^n`; `m_n = (n-2)!((n-2)/(n-1)^2)^(n-2)` is the
Knopp-Sinkhorn minimum of the permanent over doubly stochastic matrices with a zero entry;
`E = B - J_n/n`; `d_j = ||col_j(B) - 1/n||^2`; `K = -log cap(A)` is the Sinkhorn scaling cost
and `B` the doubly stochastic scaling of `A`; `lambda_2(B) = 1 - sigma_2(B)` is the spectral gap.

## 5. The `n >= 8` episode: what was claimed, what is true

During the afternoon I reported that Theorem 2 plus Lemma 2' close Dittert's conjecture for every
`n >= 8`, with margin 2.68x at `n = 8`. **That was wrong, and the record was corrected the same
evening.** The deduction is:

- (a) margins `mu^2 = |u|^2 + |v|^2 <= 2 gamma_n kappa_n` (Theorem R, Lemma 3(a));
- (b) `per(A) <= gamma_n`; (c) `per(B) >= m_n` (zero entry), so `K >= log(m_n / gamma_n)`;
- (d) Theorem 2 with `per(B) = e^K per(A) <= e^K gamma_n` gives `||E||^2 <= 2nK`, hence
  `lambda_2(B) >= 1 - sqrt(2nK)`;
- (e) Lemma 2' gives `K <= Phi(lambda_2(B))`, decreasing in `lambda_2(B)`.

Together `K <= Psi(K) := Phi(1 - sqrt(2nK))`. `Psi` is increasing, positive at `0`, and has a
pole at `K = 1/(2n)`, so the solution set of `K <= Psi(K)` is **two branches**, `[0, K_1]` and
`[K_2, infinity)` (`study/branch-structure.py`, 30 digits). At `n = 8`: `K_1 = 0.0037`,
`K_2 = 0.047`, and a counterexample needs `K >= 0.0098`. So:

- the small-cost branch is excluded at every `n >= 8` (that is what the "2.68x" measured);
- the large-cost branch is **not excluded by anything in the record**. On it
  `lambda_2(B) <= 1 - sqrt(2 n K_2)`, which is `0.13` at `n = 8`: the scaling of the
  counterexample is near-decomposable.

What is actually proved (unit 5 of the third attack): **every counterexample at `n >= 8` has
scaling cost at least `K_2(n)` and a near-decomposable scaling; expander counterexamples do not
exist.** Dittert's conjecture at `n >= 8` reduces to the near-decomposable case, which is the
same barrier the second attack recorded. `n = 7` joins this statement as soon as Theorem 2 holds
with constant `1/n` (the two-column form), and not with `1/(2n)`.

Corrected files: `study/application.md` (section 2, correction paragraph), `study/lemma2-prime.md`
(sections 5 and 6), units 5 and 6, and the memory file. Lesson recorded: in any fixed-point
argument, compute the whole solution set before reading off a margin.

## 7. Traps met, so they are not met again

- **Lean: `native_decide` interprets imported definitions** unless the library sets
  `precompileModules = true`; measured three times slower (100 minutes and unfinished, against
  47 minutes). The library needs a root module (`Cert.lean`); do not set `roots` (it shrinks the
  module set to the roots alone).
- **Lean: a closed nullary `def` is evaluated at module load.** Make big tables `(_ : Unit)`
  functions and the check `certOK (_ : Unit)`, so it runs once inside `native_decide` and imports
  are free.
- **Lean: array literals of thousands of entries exceed `maxHeartbeats`**; carry data as strings
  and parse at run time. Orbit labelling by fixpoint propagation is too slow; use flood fill.
- **`eps = n mod 2`** in the Dittert polynomial: at `n = 5` the functional is multiplied by `s`,
  at `n = 6` it is not, and `q_B = n^n / n^eps`. Copying the `n = 5` constants to `n = 6` breaks
  only the identity check, silently.
- **Use `A + d J`, not row deletion**, when certifying `A >= 0` with `A 1 = 0`: it is `dim` times
  better conditioned (`lambda_2` from `1.5e-4` to `0.156` at `n = 6`, Higham margin from 2.45x to
  2548x).
- **Symmetry check on orbit indices is wrong**; compare the values (`(i, j)` and `(j, i)` can lie
  in different orbits with equal values).
- **The `exactory-math` gate** refuses a Bash call that mixes an `exactory-math` command with a
  heredoc, and any heredoc whose text contains an unbalanced apostrophe. Write files in one call,
  run the command in the next.
- **`fail` before `journal add`** removes the strategy from the openings even though no move was
  journalled; restore by editing `preconditions.json` (verdict `yes`, drop the note) and rerunning
  `plan` and `rank`.
- **Walk rules**: the opening move has empty `step_cites`; a move continuing the same strategy
  has empty `step_cites`; `attack-the-negative-side` precedes `ladder-the-parameter` and
  `verify-formally-with-lean4`, so it must open if it is to run at all; Lean closes the walk; at
  most one `unknown`-verdict strategy per walk.
- **Fable subagents**: at most two at once; give the complete brief in the prompt (they start with
  empty context); make them write to `study/route-*.md` with a resume marker; re-verify every
  result independently before believing it (both routes were right today, but check).
- **Machine load**: other sessions ran 38 Python processes at load 200. Any timing measured today
  under that load is an upper bound. Check `uptime` before blaming a build.
- **Memory** (`<agent-memory>/`): `dittert-conjecture-study.md`
  and `quantitative-van-der-waerden.md` carry the durable facts and the resume instructions.
