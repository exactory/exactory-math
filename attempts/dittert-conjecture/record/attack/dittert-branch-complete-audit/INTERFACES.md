# Dimensional interfaces

For a global maximizer define gamma=n!/n^n, P=per(A), delta=gamma-P. The unchanged exact identity is P+delta-gamma=0. Each boundary component supplies H>0 with P+delta-gamma>=H on every feasible case. Different dimensions use disjoint variables. No numerical gain in one compensates for a missing case in another.
