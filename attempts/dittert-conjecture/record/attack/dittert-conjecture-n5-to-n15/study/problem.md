## 3. What was learned, as constraints on the plan

1. **Route in print, analytic (boundary exclusion), and exactly where it stops.** Kafidov's argument is dimension-generic except its final rational inequality. Evaluated exactly over Q for n = 4..17 (`study/kafidov-threshold.py`, run 2026-09-03): the ratio (m_n - gamma_n) / (n^3 m_n^2 / (4 (1 - gamma_n))) is 1.869 at n = 16, **0.987 at n = 15**, 0.535 at n = 14, 0.298 at 13, 0.172 at 12, 0.104 at 11, 0.065 at 10, 0.044 at 9, 0.031 at 8, 0.025 at 7, 0.022 at 6, 0.023 at 5. Removing Bernoulli (exact (1-t)^n, minimised over 0 < delta <= gamma_n in 60-digit arithmetic, evidence only) still fails at n = 15, by 2.1e-5 gamma_15 against a gap m_15 - gamma_15 = 2.5e-3 gamma_15 (0.8 percent of the gap), and at n = 14 by 2.5e-3 gamma_14 against 2.9e-3 gamma_14. So the published dilation is within one percent at n = 15; each dimension down needs roughly a factor 1.9 more (gamma_n grows by ~e per step down while the threshold 2/(n^3 (n-1)^2) grows by ~1.4).
2. **Where the analytic loss is.** The dilation multiplies all n rows by (1-t)^{-1} with t ~ sqrt(n delta), so the permanent loses a factor (1-t)^n ~ 1 - n^{1.5} sqrt(delta); the near-maximiser's row and column sums deviate in l2 by only ~sqrt(2 rho), rho + sigma <= delta. The comparison per(S) >= per(B) >= m_n for some doubly stochastic B <= S discards the excess mass n t/(1-t) of S over B. Equivalently the argument proves cap(A) >= (1-t)^n for the capacity cap(A) = inf_x prod_i (Ax)_i / prod_j x_j, and per(A) >= cap(A) m_n by Sinkhorn scaling (A is fully indecomposable by Cheon-Wanless Thm 3.2) plus Knopp-Sinkhorn. Any lower bound on cap(A) (or on per(A) directly) that loses less than the factor n^3 m_n^2 extends the analytic route downward; this is the one missing input on that route. Not in print for any n <= 15.
3. **Route in print, computational (exact SOS), and its documented scale.** At n = 4 the certificate needed the pairwise preordering at the minimal degree, 153 + 136 x 17 Gram entries, MOSEK numerics, denominator 1331 for the small blocks, and `native_decide` in Lean. The paper does not use the symmetry group G_n = (S_n x S_n) x| Z_2. Nothing in print for n >= 5.
4. **Settled ranges.** n = 2, 3, 4, 16, and every n >= 17 are proved; no partial result for any n in 5..15 beyond the structural facts (maximiser is positive or fully indecomposable with no single-block zero pattern, row/column sums within sqrt(2 n!/n^n)).
5. **No canonical formal statement** exists in the formal-conjectures repository; the claim is stated as in Minc's Conjecture 28 and identically in all three 2026 preprints.
6. **Cheon-Wanless Thm 3.2 was itself computer-assisted for 4 <= n <= 11** (interval narrowing), which is a precedent for a per-dimension machine-checked residue in exactly this range.
